# velora

Простой RESTful API на .NET Core для управления списком событий. Реализует базовые CRUD-операции (Create, Read, Update, Delete).

## Запуск
После запуска API доступно по адресу https://localhost:7015 или http://localhost:5021

## Тестирование
Для проверки работы API можно использовать Swagger https://localhost:7015/swagger
